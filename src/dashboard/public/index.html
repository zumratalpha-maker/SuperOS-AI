快速开始

1
启动系统：在终端执行 npm run start 进入命令行模式，或 npm run electron:dev 启动桌面版 桌面版启动后，按 Alt+Space 唤醒输入框
2
文字/语音切换：在指令窗口右上角点击「语音」模式，再点麦克风图标即可用语音下达指令 语音使用浏览器 Speech API（Chrome 支持最好）
3
下达指令：用自然语言描述你想做的事，例如： 「帮我在通义万相生成一张宇宙飞船的图片」 「制作一个口播短视频，主题是AI改变生活」 「打开微信发消息给张三」 「帮我下载这个YouTube视频」
4
创作流水线：说「做口播视频」「做漫剧」「做图文」会进入交互式流水线，系统会： 选择工具 → 检查登录 → 展示计划 → 你确认 → 自动执行 → 关键节点暂停让你确认

核心能力

A
自学能力：遇到不会的任务，系统自动上网搜索教程、提取操作步骤、存入技能库。下次再遇到同类任务直接执行。 技能库可在「技能库」标签页查看和管理
B
桌面 App 优先：如果桌面安装了 Grok、豆包等应用，系统会优先使用桌面版（已登录），而不是打开网页重新登录。
C
记忆与习惯：系统会记住你的操作习惯（常用路径、偏好工具、活跃时间），越用越聪明。 记忆数据可在「记忆」标签页查看
D
安全边界：高风险操作（删除文件、执行脚本等）会自动弹出确认，不会误操作。 安全日志可在「安全」标签页查看

控制面板

1
启动面板：执行 npm run dashboard 然后访问 http://localhost:3200 桌面版右键托盘图标 → 控制面板
2
录制工作流：在命令行输入 录制工作流 [名称]，然后手动操作，完成后输入 停止录制。下次输入 回放 [名称] 即可重复。
3
插件扩展：遇到未知场景，系统会自动调用 AI 生成插件代码，自动加载执行。你也可以手动放插件到 src/plugins/ 目录。

# Blueprint Plan：短视频流水线（Phase C）

> 在 Phase B Jarvis 能力扩展完成后的 **C. 短视频流水线**。
> 本文档为规划初稿，待用户补充需求后细化实现步骤。

---

## 一、目标与约束

1. **目标**：实现 Win11 自动化短视频生产流水线——从素材到发布的可控流程。
2. **约束**：复用 DirectShell、Jarvis、Orchestrator；优先剪映（已支持 open_app）；不引入新视觉依赖。
3. **范围**：先实现「单条视频生产」最小闭环，再扩展批量与发布。

## 三、技术框架（初稿）   

### 3.1 流水线阶段划分

```
素材准备 → 剪辑编排 → 导出 → [可选] 发布
   ↑           ↑         ↑
本地/API   a11y_sequence  click 导出
```

### 3.2 与现有能力映射

| 阶段 | 现有能力 | 扩展点 |
|------|----------|--------|
| 打开剪映 | resolveAndLaunch + open_app | 已完成 |
| 导入素材 | click + type（路径） | 需明确剪映导入 UI 流程 |
| 加字幕/配音 | click 菜单 + type | 依赖剪映界面结构 |
| 导出 | click 导出 + type 文件名 | 规则兜底可扩展 |
| 发布 | 各平台 Web 或客户端 | 需单独 Blueprint |

### 3.3 实现优先级（待需求确认后定）

1. **P0**：打开剪映 + 导出到指定路径（含文件名）—— 最小可验证闭环。
2. **P1**：导入本地素材（若用户素材为本地文件）。
3. **P2**：TTS 配音、字幕生成（若用户需要）。
4. **P3**：发布到指定平台（需平台 API 或 Web 自动化）。

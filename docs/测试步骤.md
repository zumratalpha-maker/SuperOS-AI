# SuperOS 测试步骤

按顺序执行以下步骤，可快速验证环境与核心功能是否正常。

---

## 一、环境准备

1. **安装依赖**
   ```bash
   cd d:\SuperOS
   npm install
   ```

2. **配置 .env**（至少配置云端 LLM，用于文案/意图解析）
   ```env
   CLOUD_API_KEY=sk-你的DeepSeek密钥
   CLOUD_API_BASE_URL=https://api.deepseek.com/v1
   CLOUD_API_MODEL=deepseek-chat
   ```

3. **编译**
   ```bash
   npm run build
   ```
   无报错即通过。

---

## 二、自动化验证脚本（推荐先跑）

在项目根目录执行：

| 步骤 | 命令 | 说明 |
|------|------|------|
| 1 | `npm run verify:core` | 验证：系统感知、结果校验、任务存储、调度器、DeepSeek 文案 API |
| 2 | `npm run verify:phase3` | 验证：长计划解析、插件管理、知识图谱、习惯学习 |
| 3 | `npm run verify:phase6-7` | 验证：安全拦截、灰名单确认、脚本检查、审计日志、插件生成 |
| 4 | `npm run e2e:short-video:dry` | 端到端「仅文案」：不打开浏览器，只测 DeepSeek 文案 + 模块导入 |

**预期**：终端里看到各模块 ✓ 或「通过」，无未捕获异常。

---

## 三、手动功能测试

### 1. 命令行 Jarvis

```bash
npm run start:jarvis
```

在 `您 >` 后输入下面指令，逐条验证：

| 输入 | 预期 |
|------|------|
| `你好` | 显示帮助/示例 |
| `打开记事本` | 记事本窗口出现 |
| `查看定时任务` | 列出当前定时任务（可为空） |
| `微信监控状态` | 显示「微信监控未启动」或「正在运行中」 |
| `查看工作流` 或 `列出工作流` | 列出已录制工作流（可为空） |

输入 `exit` 或 `Ctrl+C` 退出。

---

### 2. 控制面板

1. 启动面板：
   ```bash
   npm run dashboard
   ```
2. 浏览器打开：`http://localhost:3200`
3. 检查：总览/任务/技能库/记忆/插件/安全/使用指南 等标签可点击，数据能加载（或显示「暂无」）。

---

### 3. 桌面版（Electron）

1. 启动：
   ```bash
   npm run electron:dev
   ```
2. 按 **Alt+Space** 唤出输入框。
3. 测试：输入「打开记事本」回车，应看到聊天记录与执行反馈。
4. 切换「语音」模式，点麦克风（需浏览器支持语音识别）。

---

### 4. 微信监控（可选）

- 先打开 **桌面微信** 并登录小号。
- 在 Jarvis 里输入：`启动微信监控`
- 用手机给该小号的「文件传输助手」发一句指令，如：`打开记事本`
- 看电脑端是否执行并把结果发回微信；再输入 `停止微信监控` 停止。

---

### 5. 定时任务（可选）

在 Jarvis 里输入：

- `每天19点发小红书`
  - 应提示「定时任务已创建」并显示 cron 与下次执行时间。
- `查看定时任务`
  - 应列出刚创建的任务。
- `删除定时任务 1`
  - 应删除该任务。

---

### 6. 语音识别（可选，仅 Windows）

在 Jarvis 里输入：

- `启动语音识别` → 应提示「语音识别已启动」。
- 对着麦克风说一句指令（如「打开记事本」），看是否识别并执行。
- `停止语音识别` → 停止监听。

---

### 7. 进度浮窗中文（可选）

触发一个多步任务（如：做口播视频 并走完若干步），观察桌面右下角 **SuperOS 进度浮窗**：步骤说明应为正常中文，无乱码。

---

## 四、完整端到端（需网络 + API）

若已配置好 `.env` 且需要测「文案 → 文生图」完整链路：

```bash
npm run e2e:short-video 春天
```

会依次：DeepSeek 生成文案 → 打开通义万相文生图 → 保存图片到 `output/e2e_*`。  
首次会拉浏览器，可能较慢。

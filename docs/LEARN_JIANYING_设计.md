# 剪映学习模式设计（v2）

## 一、核心原则

1. **记录 = 光标对准，不点击**。用户只负责把光标移到要学习的按钮上，点击由自动化执行。
2. **进入下一界面 = 用户手动操作**。每步之间用户需手动进入对应界面，再把光标对准下一目标。

## 二、实际剪映流程（用户反馈）

- 点「开始创作」→ **直接进入大画面**（编辑界面）
- 部分版本有弹窗，部分无弹窗；流程需可跳过

## 三、步骤设计

| 步骤 | 界面 | 用户操作 | 记录内容 |
|------|------|----------|----------|
| 1 | 欢迎页 | 把光标移到「开始创作」上（不点击） | 剪映\|开始创作 |
| 2 | 若有弹窗 | 手动点开始创作进入→把光标移到弹窗内「开始创作」 | 剪映\|开始创作(弹窗) |
| 3 | 编辑界面 | 手动进入编辑界面→把光标移到「导入」 | 剪映\|导入 |
| 4 | 编辑界面 | 把光标移到「导出」 | 剪映\|导出 |
| 5 | 导出弹窗 | 手动点导出→把光标移到目标（若有） | 剪映\|导出设置 |

- 步骤 2、5 可输入 s 跳过（若无弹窗）
- 每步提示明确：「把光标移到 XXX 上（不用点击），保持不动」

## 四、与自动化衔接

- 学到的 (xRel, yRel) 供 `clickByName` 优先使用
- 自动化时：用学到的坐标执行点击，无需用户再点

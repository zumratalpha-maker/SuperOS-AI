# Phase C 短视频流水线 — 需求说明（初稿）

> 基于 `BLUEPRINT_短视频流水线_PhaseC.md` 与用户反馈整理，供开发参考。未明确项可后续补充。

---

## 一、核心目标

实现 **Win11 自动化短视频生产流水线**：从素材准备到剪辑导出、可选发布的完整流程，支持听取用户想法并拆分任务执行，条件允许时并行处理。

---

## 二、已确认需求

| 维度 | 当前选择 / 说明 |
|------|-----------------|
| **剪辑软件** | 剪映（已支持 open_app，优先复用） |
| **触发方式** | 听取详细想法 → 拆分任务分步骤执行；条件允许时并行部分任务 |

---

## 三、已补充（按你写的基础 + 线上技巧）

基于你写的基础，补充以下选择；有不同偏好可直接修改。

| 维度 | 选择 | 说明 |
|------|------|------|
| **素材来源** | AI 生文字 → 文字生成图片 → 图片生成视频 | 按线上已验证技巧执行，各环节均有敲门：① 文案用 LLM（Ollama/云端）② 文生图用 Stable Diffusion / Midjourney API / 通义万相等③ 图生视频用 Runway / 可灵 / 即梦等。均按线上教程的 prompt 技巧、参数设置来。 |
| **配音/字幕** | TTS 配音 + 自动字幕 | 文案生成后 TTS 配音（Ollama TTS 或云端）；剪映可自动识别或导入 SRT，有成熟流程。 |
| **剪辑流程** | 剪映：导入素材 → 加字幕/配音 → 导出 | 打开剪映 → 导入（本地图片/视频）→ 加字幕或配音轨道 → 导出。P0 导出已完成；P1 导入本地；P2 TTS 与字幕。 |
| **发布平台** | 抖音、B 站、小红书、视频号助手 | 先做 Web 端填标题、选分区；自动上传需各平台 API 或创作者中心接口，可后续接入。 |
| **启动入口** | Jarvis 语音 + 自然语言；可扩展定时/一键按钮 | 与现有 Jarvis 联动，说「帮我做一条 XXX 主题的短视频」即拆任务执行；条件允许时并行（如同时生成文案和图片）。 |

---

## 四、实现优先级（初定）

1. **P0**：打开剪映 + 导出到指定路径（含文件名）— 最小可验证闭环
2. **P1**：导入本地素材
3. **P2**：TTS 配音、字幕生成
4. **P3**：发布到指定平台（需平台 API 或 Web 自动化）

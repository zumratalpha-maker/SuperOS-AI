## 一、剪映（JianyingPro / CapCut）

### 1.1 已知有效策略

| 场景 | 策略 | 说明 |
|------|------|------|
| 开始创作 | 坐标优先 (0.68, 0.14) | UIA 常失败，自研坐标点击可靠；需传入 `窗口名\|按钮名` 格式 |
| 开始创作(弹窗) | 坐标 (0.5, 0.12) | 点击开始创作后弹出的项目选择模态框；findJianyingProjectModalHwnd 定位，点击弹窗顶部居中 |
| 导出（主窗） | 坐标优先 (0.92, 0.06) | 编辑界面右上角导出按钮；UIA 元素查找不可用 |
| 导出对话框 | findExportDialogHwnd | 先 Root 按标题；再 parentPid 顶级窗口名；再子窗口树 |

### 1.2 剪映窗口流程（实测）

| 步骤 | 窗口状态 | 操作 |
|------|----------|------|
| open_app | 小窗口1（欢迎页） | 仅有此窗口，上有「开始创作」 |
| click 开始创作 | 小窗口1 上点击 | 触发后：大窗口（主编辑区）出现 + 小窗口2（项目选择弹窗）出现 |
| click 开始创作(弹窗) | 小窗口2 上点击 | 弹窗关闭，只剩大窗口，可进行 导入/导出 |

逻辑要点：第一步是小窗口；点「开始创作」后大窗口才出现，紧接着又出现小窗口2；第二步要在大窗口坐标系内点击，由顶层小窗口2 接收。

### 1.3 已知失效模式

| 失效现象 | 可能原因 | 修正建议 |
|----------|----------|----------|
| Element not found: 开始创作 | UiaSniper 中文编码 / 剪映未暴露 Name | 走坐标分支，确保 `nameOrTarget` 含 `剪映` |
| 未找到导出对话框 | 对话框标题因版本/语言不同 | 扩展 EXPORT_DIALOG_NAMES；增加顶级窗口名检查 |
| 坐标点击偏移 | 剪映 UI 改版、窗口缩放 | 调 (0.5,0.38) / (0.92,0.06)；或引入多策略相似度 |

### 1.3 版本差异（待补充）

- 剪映国内版 vs CapCut 国际版：部分标题/控件不同
- 导出对话框：可能为「导出」「导出视频」「导出设置」或英文 "Export"

## 四、通用规则

1. **同窗口点击**：必须传 `窗口名|按钮名` + `targetHwnd`，否则应用专用分支不触发
2. **坐标 fallback**：UIA / inject 失败时，按应用维护固定坐标
3. **对话框检测**：初始延迟 + 多轮重试（如 1200ms + 8×400ms）
4. **中文编码**：UiaSniper 与 Node 间可能乱码，坐标/快捷键可规避

## 五、网页创作工具（网络学习步骤，2026-03）

> 来源：全球搜索豆包、通义万相、可灵、即梦、剪映官方教程与用户指南

### 5.1 豆包（Doubao）文生图

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 访问 www.doubao.com | 登录后左侧菜单点「图片生成」 |
| 2 | 进入图片生成 | 点「生成」进入文生图模式 |
| 3 | 输入提示词 | 输入框：主体+场景+风格+细节，示例：「一只橘色短毛猫，趴在窗台上晒太阳，窗外是花园，写实风格，午后阳光柔和」 |
| 4 | 设置参数 | 生成数量1-4、尺寸1:1/16:9/9:16、风格强度60%-80% |
| 5 | 点击生成 | 等待10-30秒 |
| 6 | 下载 | 「我的作品」中批量选后下载 |

### 5.2 通义万相（Tongyi Wanxiang）文生图

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 访问 tongyi.aliyun.com/wanxiang | 或直达 text-to-image |
| 2 | 点「文本生成图像」 | 进入创作界面 |
| 3 | 输入描述 | 公式：主体+场景+风格，示例：「25岁中国女孩，室外阳光明媚的花园，商业摄影风格」 |
| 4 | 点「生成创意画作」 | 等待出图 |
| 5 | 下载原图 | 或再次生成、复用创意 |

**直达文生图 URL**：`https://tongyi.aliyun.com/wanxiang/generate/image/text-to-image`

### 5.3 可灵（Kling AI）图生视频

### 6.1 网页应用 OCR 优先（2026-03，按 UIA_OCR_终极蓝图）

| 策略 | 说明 |
|------|------|
| **OCR 首探** | 通义万相、豆包、可灵、即梦、Gemini 等 click 时先走 OCR，跳过 UiaSniper（directshell 中文编码易乱码） |
| **记忆复用** | OCR 成功 → 写入 learned_actions → 下次优先走记忆坐标 |
| **区域模板** | 通义万相输入框：窗口上半 60%，生成/下载：全窗扫描 |

### 6.2 网页应用 open_app 窗口查找（2026-03）

| 失效现象 | 原因 | 修正 |
|----------|------|------|
| 未找到窗口: 通义万相 | `start "" url` 在已有浏览器新标签打开，标题需 2～5 秒才更新；原等待 400ms 不足 | runA11ySequence：URL 类应用 openWaitMs=2500，retryOpts={maxAttempts:12, intervalMs:300} |
| 通义万相标题未匹配 | 页面 title「万相 \| 领先的AI视频与图像生成模型」，部分浏览器显示不全 | WINDOW_NAME_ALIASES 扩展：阿里云、领先的AI、通义、AI视频与图像 |

### 6.2 网页应用 click 失败：UIA 编码 + OCR 兜底时机（2026-03）

| 失效现象 | 原因 | 修正 |
|----------|------|------|
| Window not found: ͨ������ | directshell/UiaSniper 接收中文 target 时编码错误（UTF-8 vs 控制台） | **OCR 优先**：通义万相/豆包/可灵/即梦/Gemini 在 UiaSniper 前走 tryOcrClickByName |
| inject 超时、OCR 无法获取窗口尺寸 | 窗口在长时间 UiaSniper 重试后失焦 | tryOcrClickByName 入口先 bringWindowToFront(hwnd) + 延迟，确保窗口在前台 |
| OCR 成功未复用 | 首次 OCR 定位后未写入记忆 | appendLearnedAction(source:ocr)，后续优先走 learned_actions |

**策略**：按 UIA_OCR_终极蓝图，网页应用「首探靠 OCR → 成功写入记忆 → 后续复用坐标」。

### 6.3 双屏环境「无法获取窗口尺寸」（2026-03）

| 失效现象 | 原因 | 修正 |
|----------|------|------|
| OCR 兜底失败：无法获取窗口尺寸 | 双屏时 GetWindowRect 可能失效或返回异常；副屏坐标可为负 | getWindowRectFull 增加 fallback：GetClientRect + ClientToScreen，双屏/副屏更可靠；坐标 regex 支持负值 |
